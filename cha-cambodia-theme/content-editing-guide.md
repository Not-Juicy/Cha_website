# CHA Content Editing Guide

## How It Works

The website uses Advanced Custom Fields (ACF) — a free WordPress plugin — to let you edit text and images directly from the WordPress admin. No coding needed.

## Setup (one time)

1. **Install the plugin**: Go to Plugins → Add New → search "Advanced Custom Fields" → Install → Activate
2. **You're done!** The "CHA Content" menu will appear in your WordPress sidebar automatically.

## Editing Content

1. Go to Dashboard → **CHA Content**
2. You'll see tabs organized by section:
   - **Hero** — The big banner at the top of the homepage
   - **Statistics** — Numbers like "12+ Provinces"
   - **How We Help** — The four feature cards
   - **News & Events** — Latest news items
   - **CTA Banner** — The red donate call-to-action
   - **About Section** — Vision & Mission statements
   - **Contact & Footer** — Address, phone, email, hours
3. Click any tab, edit the fields, and click **Save Changes**

## Tips

- **Images**: Upload new images directly from the field — click the image, then "Add to" to choose from your Media Library or upload new ones
- **Text**: Edit any text field and save — changes appear immediately on the live site
- **Text areas** (like the address): You can press Enter for a new line
- **Phone numbers**: Update the display version AND the "digits only" version (for click-to-call links)

## What You Can Edit

| Tab | What's Editable |
|-----|----------------|
| Hero | Background image, title lines, paragraph, CTA button text |
| Statistics | Numbers and labels for all 3 stats |
| How We Help | Section heading, subtitle, all 4 card titles & descriptions |
| News & Events | Section heading, subtitle, all 3 news item images/dates/titles/descriptions |
| CTA Banner | Heading, text, button |
| About Section | Heading, lead paragraph, vision & mission labels & text, team image |
| Contact & Footer | Heading, address, phone, email, hours, footer tagline, copyright |

## Need Help?

If you get stuck, contact your developer or check the ACF documentation at https://www.advancedcustomfields.com/resources/
